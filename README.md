# Payroll Management System using Python & Excel
## Overview
This project is a Payroll Management System developed using Python and Excel. It helps manage employee salary records, attendance, bonuses, deductions, and payroll calculations efficiently.
## Author
Kamil Abbas
## Features
- Employee record management
- Salary calculation
- Bonus and deduction management
- Attendance handling
- Excel file integration
- Payroll report generation
- User-friendly interface
- ## Technologies Used
- Python
- Excel
- OpenPyXL
- File Handling
## Project Structure
├── main.py
├── employees.xlsx
├── payroll_reports/
├── screenshots/
└── README.md
## How to Run
1. Install Python
2. Install required libraries
3. Run the main Python file
