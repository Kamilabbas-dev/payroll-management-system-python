# Payroll Management System using Python & Excel
## Overview
This project is a Payroll Management System developed using Python and Excel. It helps manage employee salary records, attendance, bonuses, deductions, and payroll calculations efficiently.

- Salary calculation

- Attendance handling
- Excel file integration
- Payroll report generation
- User-friendly interface
